# Gaming Everything

A client-side Minecraft 1.20.1 mod that gives the game an animated RGB gaming look.

- Animated rainbow tint on living entities, items and blocks
- Colorful world wash, smoothly changing sky and RGB particles
- Animated HUD frame and crosshair
- Press **G** for individual toggles, animation speed and color intensity
- Fabric and Forge support; no server installation required

Build with `gradlew.bat build`. Loader jars are written to `fabric/build/libs` and `forge/build/libs`.
