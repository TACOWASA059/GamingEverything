# Gaming Everything

ゲーム上のさまざまなものを、ゲーミングPCのように刻々と変化する虹色へ変える Minecraft 1.20.1 クライアントMODです。

- 生物・プレイヤー・アイテム・ブロックのRGB着色
- 画面全体の色彩効果、虹色の空、RGBパーティクル
- 虹色のHUDフレームとクロスヘア
- **Gキー**で個別切り替え・変化速度・色の強さを設定
- Fabric / Forge両対応、サーバーへの導入不要

`gradlew.bat build` でビルドできます。jarは `fabric/build/libs` と `forge/build/libs` に出力されます。
